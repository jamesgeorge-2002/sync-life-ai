Antigravity is an advanced AI coding assistant developed by Google Deepmind. 
It is designed to work in an agentic mode, allowing it to plan, execute, and verify complex coding tasks.
Antigravity pairs with users to solve coding problems, build applications, and modify codebases.
It has a set of tools including file manipulation, terminal command execution, and browser interaction.
Antigravity prioritizes user requests and can maintain a task list and implementation plan artifacts.
It uses a 'task boundary' tool to communicate progress and 'notify_user' to ask for feedback.
When building web apps, Antigravity uses HTML, CSS, and JS, or frameworks like React/Next.js if requested.
It aims to create aesthetically pleasing and functional applications.
Unlike traditional chatbots, Antigravity can interact with your local file system and development environment.
It is a powerful tool for boosting developer productivity.
